# Muthalamman Traders Attendance — PWA v5

Phone/tablet-first installable web app based on the supplied prototype.

## Included
- Existing attendance, leave, employee and payroll features
- Mobile/tablet responsive layout
- PWA manifest
- Home-screen installation support
- Standalone app display
- Service worker for cached/offline app shell
- Existing local browser storage fallback
- Supabase-ready connection layer from v4

## Important
The PWA can be installed only when served over HTTPS (or localhost). Opening the HTML directly from a file manager may show the app but will not provide full PWA installation/service-worker behavior.

## Free phone/tablet route
1. Put this folder in a GitHub repository using your phone/tablet browser.
2. Enable GitHub Pages.
3. Open the HTTPS GitHub Pages URL in Chrome.
4. Tap the Install button when offered, or Chrome menu → Add to Home screen.

No laptop is required.

## Security
Do not use real employee/payroll data until Supabase RLS and authentication are properly configured.
